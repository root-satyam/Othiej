# 📖 Bot Setup & Usage Guide

**⚠️ Disclaimer:** This project is intended for educational purposes only. Please use it responsibly and in accordance with Discord's Terms of Service.

## 🛠️ Getting Started

Follow the steps below to configure and run the bot.

### 1. Create Your Discord Bot
1. Visit the [Discord Developer Portal](https://discord.com/developers/home).
2. Create a new application.
3. Navigate to the **Bot** section and create your bot.
4. Enable the required Gateway Intents under **Privileged Gateway Intents**.
5. Reset your bot token and copy the new token.

### 2. Configure the Bot
1. Open the main Python file (`main.py`).
2. Locate the configuration section.
3. Enter your Discord bot token.
4. Configure the **Whitelist (WL) ID** if required.
   - Enter your Discord user ID to restrict access to a specific user.
   - Leave the WL ID empty if you want the bot to be accessible to everyone.

> **Note:** Leaving the WL ID empty disables the whitelist restriction. Make sure this is intentional.

### 3. Invite the Bot
1. Generate an invite link from the Discord Developer Portal.
2. Select the required bot permissions.
3. Invite the bot to your Discord server.
4. Ensure the bot has the necessary permissions to execute its commands.

### 4. Start Using the Bot
Once the bot is online, open your Discord server and use:

`!help`

This command displays the available commands and their usage instructions.
